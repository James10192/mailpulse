## Contacts

La page `Contacts` permet de créer, modifier et consulter les contacts d’une organisation. Un contact peut contenir email, prénom, nom, téléphone, statut d’abonnement, tags et valeurs de champs personnalisés.

## Import CSV

L’import CSV sert à créer plusieurs contacts en une opération. Les limites du plan sont appliquées pendant l’import, afin d’éviter de dépasser les quotas de contacts.

## Tags

Les tags structurent l’audience par contexte : source, événement, intérêt, pipeline commercial ou campagne. Ils sont réutilisables dans les segments et les automations.

## Champs personnalisés

Les champs personnalisés ajoutent des données métier aux contacts. Les types supportés couvrent texte, nombre, email, URL, date, liste de choix et booléen.

## Segments

Les segments résolvent dynamiquement des contacts selon des règles : abonnement, score d’engagement, dates, tags et données disponibles. Ils servent d’audience pour les campagnes et de base pour certaines actions.
