## Lifecycle

A campaign can be drafted, edited, sent immediately, or scheduled. Scheduled campaigns are processed by GitHub Actions through the protected cron endpoint.

## Editor

The editor uses TipTap with rich text, links, images, tables, alignment, colors, variable mentions, and character count. Snippets let users reuse frequent content blocks.

## Personalization

Available variables include `{{firstName}}`, `{{lastName}}`, and `{{email}}`. Custom fields can be added depending on organization data.

## Tracking

MailPulse adds open, click, and unsubscribe tracking. Resend webhooks complement those events with delivered, bounced, complained, and other statuses.

## Calendar

The calendar groups scheduled campaigns so teams can review upcoming sends and avoid overlaps.
