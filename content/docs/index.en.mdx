MailPulse brings email campaigns, contacts, capture pages, WhatsApp, automations, analytics, and Filon recovery into one workspace.

## What the app can do today

- Manage contacts with CSV import, tags, custom fields, and segments.
- Create email campaigns, edit them with TipTap, use snippets, and schedule delivery.
- Track opens, clicks, bounces, complaints, and unsubscribes.
- Publish public capture pages at `/capture/{slug}`.
- Configure senders and sending domains through Resend.
- Send WhatsApp messages through Meta Cloud API or WhatsApp Web QR code.
- Build visual automations with product triggers.
- Connect Filon to prepare and run recovery sequences.
- Use GitHub Actions for scheduled jobs, not Vercel Cron.

## Language and theme

The documentation is available in French at `/docs` and English at `/en/docs`. It follows MailPulse light and dark themes.

## Key idea

MailPulse does not force one customer infrastructure. Users can use their own domain, Meta WhatsApp, WhatsApp Web, or MailPulse managed resources when the platform enables them. External limits are visible in the UI and in this documentation.
